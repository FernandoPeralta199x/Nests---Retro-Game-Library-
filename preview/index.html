Armazenamento de arquivos

Defina como as ROMs serão organizadas na pasta de destino do NESTS.

Destino final: /download0/nests/roms/[console]/

No PS5 nativo, o app procura volumes USB montados e graváveis em /usb0–/usb7. A prévia web não consegue detectar discos USB nem gravar em /download0; nela, esta opção só demonstra a preferência.

Controles

Teclado: setas para navegar, Enter para selecionar, Esc para voltar. Controle: D-pad, A/Cross e B/Circle (mapeamento do navegador).

Ambiente

Esta é uma prévia web. Não representa uma aplicação nativa nem acessa APIs do PS5.

Armazenamento

Favoritos e arquivos pessoais usam o armazenamento do navegador.
